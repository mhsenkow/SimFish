Privacy

Effective 15 October 2026.

What the game stores

Tank saves, settings, achievements, and optional species notes live on your device (or Steam Cloud on desktop when enabled). We do not operate an account system for the game.

What we do not collect

No advertising SDK, no analytics SDK, no third-party tracking, and no sale of personal data. The App Store / Steam / GitHub may collect install and crash data according to their own policies.

Network use

Optional features may contact the network (for example checking for an optional on-device language model download on some builds, or Steam features when you use Steam). Core aquarium play works offline.

On-device companion

Where a local language model is available, generated lines stay on device. iOS builds use template voice by default and do not require a cloud AI service.
