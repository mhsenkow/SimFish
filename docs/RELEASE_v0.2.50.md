# walstad loom v0.2.50

Released October 27, 2026. Long-run ecology stays honest, first-run dialogs
queue cleanly, and fish silhouettes read better at tank scale.

## Ecology that survives the clock

Soil deposits no longer vanish when terrain re-syncs. Algae blooms follow the
lamp instead of spawning in the dark. Dead clumps return nutrients as litter.
Fish births and plant succession respect carrying capacity, so a living Walstad
tank does not explode into an unplayable crowd after a few minutes.

## Quieter first night, clearer first run

Shrimp no longer rebuild a full tank mind snapshot every night tick. Mind
cadence stretches under population pressure. Intro dialogs share one FIFO queue
so stacked onboarding prompts cannot steal clicks from the tank.

## Silhouette polish

Fish heads get a stepped muzzle, darker pupils, and fan tails with denser root
pigment. Foliage lighting shares one include so leaf meshes stay consistent.
