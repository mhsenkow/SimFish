# walstad loom v0.2.41

Released October 16, 2026. The tank fills the desktop window.

## No black bars

The window used to stay locked to a 16:9 frame. On a 16:10 desktop the leftover
strip was empty and black. The view now grows to the monitor. A taller screen
shows a little more of the room above and below the tank. A wider screen shows
more to the sides.

## Also in this build

Drawn nav icons from v0.2.40, so iPad and iPhone buttons do not depend on font
glyphs the device cannot draw.
