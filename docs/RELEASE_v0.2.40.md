# walstad loom v0.2.40

Released October 16, 2026. Nav buttons draw their own icons.

## iPad and iPhone controls

IBM Plex does not include the gear, corners, people, or castle marks, and iPad
does not fall back to a symbol font. Those buttons were blank. The rail
(Create, World, Look, System, Alerts, menu, focus) and the touch cluster
(pause, camera, residents, photo, undo, build tools) now use 12×12 nearest
pixel icons. Tooltips are unchanged.

## Unchanged

Color, habitats, crowded-tank speed, and long-session retention from v0.2.39.
